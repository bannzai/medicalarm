Medicalarm ist eine Arzneimittelverwaltungs-App, die das Risiko des Vergessens von Medikamenten beseitigt. Sie wurde so konzipiert, dass sie die Verwaltung mehrerer Personen ermöglicht. Besonders nützlich für Eltern, die im Namen ihrer Kinder oder anderer Angehöriger das Medikamentenmanagement übernehmen müssen.

■ Medicalarm bietet folgende Funktionen:
 ・Sie können mehrere Medikamente registrieren und erhalten bei Einnahmezeitpunkt eine Push-Benachrichtigung auf Ihr Gerät.
 ・Es können mehrere Einnahmeberechtigte registriert werden.
 ・Sie können Ihre Einnahmeprotokolle führen, um nachzuvollziehen, wann Sie welche Medikamente eingenommen haben.
 ・Wenn die Einnahmezeit verstrichen ist und Sie das Protokoll nicht erstellt haben, erhalten Sie eine Follow-Up-Benachrichtigung, um das Vergessen zu vermeiden.
 ・Ein äußerst leistungsfähiges Benachrichtigungssystem sorgt dafür, dass Sie auch im lautlosen Modus benachrichtigt werden.

Nutzen Sie diese App, um das Vergessen von Medikamenten zu vermeiden und ein sorgenfreies Leben zu führen.
