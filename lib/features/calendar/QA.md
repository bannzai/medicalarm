# calendar QA

到達手順: ホーム下部タブの「カレンダー」をタップすると月間カレンダー画面（CalendarPage）が開く。

## 1. カレンダー画面の表示

- [ ] **AppBar タイトル**: 「カレンダー」が表示される
- [ ] **月ナビゲーション**: 画面上部に前月・翌月の矢印ボタンと現在表示中の年月（例: 2026年8月）が表示される
- [ ] **月間カレンダー**: 曜日ヘッダーと当月の日付タイルが表示され、当月以前の日付はグレーアウトされる
- [ ] **今日の強調表示**: 今日の日付タイルに丸背景の強調表示が付く
- [ ] **日記バッジ**: 日記が保存されている日付タイルにメモアイコンが表示される

## 2. 月の切り替え

- [ ] **前月へ移動**: 左矢印タップで前月のカレンダーが表示され、年月表示も更新される
- [ ] **翌月へ移動**: 右矢印タップで翌月のカレンダーが表示され、年月表示も更新される
- [ ] **月またぎの表示**: 12月→1月・1月→12月の年またぎでも正しい年月が表示される

## 3. 日付詳細シート（服薬記録の振り返り）

- [ ] **シート表示**: 当月の日付タイルをタップすると、その日の詳細シート（CalendarDayDetailSheet）が開く
- [ ] **日付見出し**: シートの AppBar に対象日付が「YYYY年M月D日」形式で表示される
- [ ] **服薬記録一覧**: その日に服薬記録がある場合、履歴画面と同じ形式のカードで一覧表示される
- [ ] **取消記録の表示**: 取消（revert）された記録も取消行として表示される
- [ ] **記録なしの表示**: 服薬記録がない日は「服薬履歴がありません」が表示される
- [ ] **プレミアム制限**: 非課金ユーザーが過去日を開くと服薬記録一覧にぼかしがかかり、「プレミアムプランの加入で閲覧が可能です」からプレミアム紹介シートが開く

## 4. 日記機能

- [ ] **日記導線（未作成）**: 日記がない日は「日記を書く」ボタンが表示され、タップで日記投稿画面（DiaryPostPage）が開く
- [ ] **日記の保存**: 日記投稿画面でメモを入力し保存すると、シートに戻った際に保存したメモが表示される
- [ ] **日記の表示（作成済み）**: 日記がある日はシートの日記セクションにメモ本文が表示される
- [ ] **日記の編集**: 編集アイコンから既存メモ入りの日記投稿画面が開き、変更を保存するとシートとカレンダーに反映される
- [ ] **カレンダーへの反映**: 日記を保存した日付タイルにメモアイコンが表示される
