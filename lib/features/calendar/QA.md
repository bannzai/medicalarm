# calendar QA

到達手順: ホーム下部タブの「カレンダー」をタップすると月間カレンダー画面（CalendarPage）が開く。

検証方法: `maestro test maestro/flows/qa_verify_calendar.yaml`（日記の新規作成導線・編集導線の 2 回実行）+ 過去日検証の一時フロー + スクリーンショット目視。実行時のシミュレータアカウントに服薬記録が無かったため、服薬記録カードの表示系は未検証（下記の各項目に明記）。

## 1. カレンダー画面の表示

- [x] **AppBar タイトル**: 「カレンダー」が表示される
- [x] **月ナビゲーション**: 画面上部に前月・翌月の矢印ボタンと現在表示中の年月（例: 2026年8月）が表示される
- [x] **月間カレンダー**: 曜日ヘッダーと当月の日付タイルが表示され、当月以前の日付はグレーアウトされる
- [x] **今日の強調表示**: 今日の日付タイルに丸背景の強調表示が付く
- [x] **日記バッジ**: 日記が保存されている日付タイルにメモアイコンが表示される

## 3. 日付詳細シート（服薬記録の振り返り）

- [x] **シート表示**: 当月の日付タイルをタップすると、その日の詳細シート（CalendarDayDetailSheet）が開く
- [x] **日付見出し**: シートの AppBar に対象日付が「YYYY年M月D日」形式で表示される
- [ ] **服薬記録一覧**: その日に服薬記録がある場合、履歴画面と同じ形式のカードで一覧表示される
  - ⏭️ 未検証: 検証アカウントに服薬記録が無く未確認（表示は履歴画面と同一の `MedicationHistoryTile` を再利用）
- [ ] **取消記録の表示**: 取消（revert）された記録も取消行として表示される
  - ⏭️ 未検証: 検証アカウントに取消記録が無く未確認（表示は履歴画面と同一の `MedicationHistoryRevertTile` を再利用）
- [x] **記録なしの表示**: 服薬記録がない日は「服薬履歴がありません」が表示される
- [x] **プレミアム制限（表示）**: 非課金ユーザーが過去日を開くと、服薬記録一覧の代わりに鍵アイコン付きの白カードと「プレミアムプランの加入で閲覧が可能です」リンクが表示される（記録・空表示は描画されない）
- [x] **プレミアム制限（導線）**: 上記リンクのタップでプレミアム紹介シート（プラン一覧）が開く

## 4. 日記機能

- [x] **日記導線（未作成）**: 日記がない日は「日記を書く」ボタンが表示され、タップで日記投稿画面（DiaryPostPage）が開く
- [x] **日記の保存**: 日記投稿画面でメモを入力し保存すると、シートに戻った際に保存したメモが表示される
- [x] **日記の表示（作成済み）**: 日記がある日はシートの日記セクションにメモ本文が表示される
- [x] **日記の編集**: 編集アイコンから既存メモ入りの日記投稿画面が開き、変更を保存するとシートとカレンダーに反映される
- [x] **カレンダーへの反映**: 日記を保存した日付タイルにメモアイコンが表示される
